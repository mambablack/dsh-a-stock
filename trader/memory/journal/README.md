# 每日复盘

每个交易日收盘写一份 `YYYY-MM-DD.md`。这是交易员最重要的文件——
**没有日志的交易日等于没发生。**

模板：

```markdown
# 2026-11-16 复盘

## 账户
- 权益 1,000,000 → 1,003,200（+0.32%），回撤 0%，持仓 2 只

## 今日操作
| 时间 | 动作 | 代码 | 股数 | 价格 | 理由 | 结果 |
|---|---|---|---|---|---|---|

## 计划 vs 实际
- 计划买了 A，实际买了 A（成交价差 +0.3%）
- 计划观察 B，B 没触发，未买

## 错误
- 无 / 违反了哪一条纪律，为什么

## 今天学到什么
- 一条可证伪的观察（进 knowledge/ 或提案）

## 明天
- 观察名单 / 触发价 / 要处理的事
```

规则：
- 只写事实，不写情绪；
- 错误必须具体（"10:32 追高 1.2% 买入，违反不追高"），不写"今天状态不好"；
- 每天至少一行"学到什么"，没有就写"无新观察"。
