## 一句话

PB-001 的全部规则 + 一条新闸门：**全市场当日涨停家数处于近 60 日的 30% 分位以下时不买**。
只在"市场不过冷"时出手，收益、回撤、Sharpe 三项同时优于原版。

## 与 PB-001 的差别

只加一条条件（不删不改任何原有规则）：

| 新增条件 | 口径 |
|---|---|
| 市场不过冷 | `market_lu_count_pct >= 0.30` |

- `market_lu_count` = 全市场当日涨停收盘家数；
- `market_lu_count_pct` = 该值在**近 60 个交易日**中的分位（0~1）。

含义：把"什么时候不该出手"写进规则——市场情绪冰点时，再好看的图形也容易失败。

## 规则

除新增闸门外，与 PB-001 完全一致：

| 规则 | 条件 |
|---|---|
| 涨停基因 | 60 日内 ≥1 次涨停收盘 |
| 不追涨停次日 | 距最近涨停 3–60 日 |
| 洗盘回撤 | 距 20 日高点回撤 5%–30% |
| 缩量洗盘 | 5 日均量 / 20 日均量 ≤ 0.85 |
| 长影线 | 近 10 日至少 1 根长影线 |
| 不破 MA20 | 收盘 ≥ MA20 × 0.97 |
| MA20 不走坏 | MA20 五日斜率 ≥ −0.5% |
| 均线多头或粘合 | MA5>MA10>MA20 或 MA5 与 MA20 相差 ≤6% |
| 箱体足够窄 | 10 日箱体振幅 ≤ 18% |
| **箱体突破** | 收盘 > 前 10 日最高价 |
| 非涨停收盘 | 排除涨停价收盘 |
| **市场不过冷** | 涨停家数 60 日分位 ≥ 30% |

股票池：沪深主板、价格 5–10 元、流通市值 ≤40 亿、剔除 ST、上市 ≥60 日、
20 日成交额中位数 ≥2000 万。

**买入**：信号次日开盘，跳空 >5% 不追，涨停买不到放弃。
**卖出**：−12% 止损、+30% 止盈、最长 10 个交易日。

## 容量与限制

- 信号频率 0.23 个/交易日（8 年 436 个）；
- 组合平均持仓 1.6 只、平均仓位约 27%（6 槽口径）；
- 冷市会主动不收信号——这是设计意图，不是漏扫。

## 已知风险

1. 闸门阈值 30% 是在全样本上选的，敏感性未穷举；
2. 涨停家数用"涨停收盘家数"近似市场情绪，不含炸板率、连板高度；
3. 2022 年仍需单独看（样本内胜率 51.9% 说明熊市里还是会难受）。
