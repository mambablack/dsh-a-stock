## 结论与下一步

1. **通用技术形态本身没有 alpha**：M-001/M-002/M-003 三条通用战法全部亏钱。
   alpha 不在"形态"里，而在**生态位**（小盘低价 + 涨停基因 + 情绪温度）里——M-004 的对比就是证据：
   同一个反转信号，全市场口径 −0.41%/笔，挪到热市小盘涨停基因池里变成 +1.49%/笔。
2. **M-004 值得继续**：它和 PB-004 用的是同一片生态，但信号不同（超跌反弹 vs 箱体突破）。
   下一步要解决的是组合构造：把单票降到 12.5%（8 槽）、或只在 PB-004 空槽时用它填窟窿，
   看组合 MDD 能否压到 20% 以内、年化能否叠加。
3. **板块动量不能当过滤器**（M-005）：加了行业动量过滤后，PB-004 的笔数从 315 掉到 177/91，每笔期望没提升，年化反而从 22.2% 降到 14.4%/10.3%——说明这套打法的 alpha 在个股形态与生态位，不在行业轮动。板块数据更适合做**盘前背景判断**，而不是硬过滤。
4. **挖掘方法固定为**：搜到思想 → 拆成条件树 → 先全市场跑一遍（看是否真有信号） →
   再挪到已验证生态位跑一遍 → 只有信号级正期望且组合可控才进入下一轮。
   这个"两步法"比直接调参省时间，也能避免在噪声上做参数搜索。
