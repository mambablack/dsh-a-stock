# 每日计划

每个交易日盘前写一份 `YYYY-MM-DD.md`，格式：

```markdown
# 2026-11-16 计划
## 账户
- 权益 / 现金 / 持仓数 / 今日新开上限

## 持仓处理
| 代码 | 股数 | 成本 | 止损 | 止盈 | 今日动作 |
|---|---|---|---|---|---|

## 计划买入
| 代码 | 名称 | 触发条件 | 计划股数 | 参考价 | 止损 | 止盈 | 打法 |
|---|---|---|---|---|---|---|---|

## 观察（不买）
- 代码 / 触发价 / 为什么观察

## 备注
- 数据时间、市场状态、任何异常
```

规则：
- 盘前计划里没写的买入，盘中不做。
- 止损价写不出来，就不许买。
- 计划与实际不符时，在收盘复盘里写明原因。
