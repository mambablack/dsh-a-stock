# 定时任务（routines）

交易员是「常驻」的：不靠你发指令，到点自己跑。驱动它的是飞书插件里的
`routines` 配置——每个时间点向交易台会话投递一条提示词，会话照 `a-share-trader`
技能执行，结果用卡片回传到飞书。

## 时间表

| 时间 | 标签 | 做什么 | 回传 |
|---|---|---|---|
| 09:00（仅周一） | 周一自评 | 读本周 journal → 出提案卡 | 提案卡 |
| 09:15 | 盘前 | 读账本/记忆 → 扫昨日信号 → 写 `plans/YYYY-MM-DD.md` | 3–6 行计划 |
| 10:30 | 盘中第 1 次 | 持仓取价 → 检查止损/止盈/条件离场 | 有则成交，无则一行 |
| 11:20 | 盘中第 2 次 | 同上 | 同上 |
| 13:30 | 盘中第 3 次 | 同上 | 同上 |
| 14:45 | 盘中第 4 次 | 同上 + 检查计划内「若突破则买」的标的 | 结论一行 |
| 15:05 | 收盘复盘 | mark → nav → check → 写 journal → 更新 handover | 复盘卡片 |

周末默认跳过（`skipWeekend`），节假日由 Agent 判断后回「今天跳过：原因」。

## 改时间 / 加任务

在 `routines:` 下追加一项：

```yaml
      - time: "14:00"
        label: "午后观察"
        prompt: >-
          【午后观察】按 a-share-trader 技能检查持仓，回一行结论。
```

字段：`time`（HH:MM，本地时间）、`label`（显示用）、`prompt`（会原样投给会话，
支持 `{date}` `{time}` `{label}` 占位）、`skipWeekend`（默认 true）。

改完保存，插件约 10 秒内热重载；用 `state.json` 的 `status.startedAt` 确认。

## 临时测试

加一条 `time` 为「当前时间 + 2 分钟」、`skipWeekend: false` 的 routine，
内容写「只回复一行：routine 正常，不要做任何事」；到点后检查：

```powershell
$st = Get-Content "$env:USERPROFILE\.dsh\feishu-im\state.json" -Raw | ConvertFrom-Json
$st.status.lastRoutine   # 应该有 label / at / chat
$st.status.lastTurn      # claimed=true, finished=true
$st.status.lastError     # 应为空
```

测完把那条 routine 删掉。

## 关闭

`routineEnabled: false`，或把整段 `routines:` 删掉。
