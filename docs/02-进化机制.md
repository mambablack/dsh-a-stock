# 进化机制：怎么"越来越像一个好交易员"

## 核心原则

**不靠聊天积累，靠可证伪的闭环积累。** 每一条知识、每一次复盘，最终都要落成
一个可以被数据检验的假设；检验不过就淘汰，不心疼。

## 四步循环

```
知识/教训 ──→ 假设卡 ──→ 回测 ──→ 纸面跟踪 ──→ 晋级 or 淘汰
   │            │           │          │
   │            │           │          └─ 满 20 笔：期望>0 晋级；滚动 20 笔 <-1% 降级
   │            │           └─ 样本内外 + 随机基准 + 消融（strategy-lab 全自动）
   │            └─ 必须能写成条件树；写不出就不是可交易知识
   └─ 原文存 knowledge/，一字不改
```

## 三种状态

| 状态 | 含义 | 能否交易 |
|---|---|---|
| `candidate` | 有回测但没纸面数据 | **不能**，只观察 |
| `tracking` | 回测通过，纸面跟踪中 | **能**，但仓位减半 |
| `verified` | 纸面 ≥20 笔且期望 >0 | 能，按标准仓位 |
| `retired` | 衰减或证伪 | 不能，保留记录 |

## 三道闸（保证 Agent 不把自己优化没了）

1. **变更有证据**：任何参数/规则/仓位调整，必须先有回测对照，且新配置在收益与回撤上
   不能同时劣于旧配置；没有证据的改动不做。
2. **新规则先进候选**：任何新知识不得直接用于交易，必须先回测 + 纸面。
3. **全部留痕**：提案（propose.py）→ 决策理由 → 落实 → 回归 → git commit → journal。
   人类保留否决权，随时可以推翻。

> 2026-11-16 起，用户把决策权交给 Agent（目标：盈利最大化），审批门从"人类批准"
> 改为"Agent 自主决策 + 证据留痕 + 人类可否决"。

## 提案卡格式

用脚本建档，不要手写（保证 id、状态、证据字段一致）：

```powershell
python scripts\propose.py new --title "收紧箱体宽度" --kind tune `
  --run "strategy-lab/runs/<run-id>" --evidence "n=480, 期望 +3.40% → +2.9%" `
  --change "box_width_10 从 0.18 收到 0.14" --impact "信号 -30%，期望 -0.5pp"

python scripts\propose.py list                     # 看所有提案与状态
python scripts\propose.py decide --id PROP-20261116-01 --approve --note "批准，下周生效"
python scripts\propose.py decide --id PROP-20261116-01 --reject  --note "样本不足"
```

生成的文件在 `trader/reports/PROP-YYYYMMDD-NN.md`：

```markdown
## 提案 PROP-YYYYMMDD-NN
- 触发：PB-001 滚动 20 笔期望降到 +0.8%（阈值 +1.5%）
- 证据：runs/xxx（n=62，胜率 52%，盈亏比 1.7）
- 建议：把「箱体宽度 ≤18%」收紧到 ≤14%，或降级为 candidate
- 影响：预计信号减少 30%，期望回升到 +2.1%（回测）
- 需要你决定：A 采纳 / B 只降级 / C 不改，继续观察
```

**状态流转**：`pending` → `approved`（Agent 落实并 git 提交）/ `rejected`（保留记录）。
风险层提案（仓位、笔数、熔断）只有人类能批准；Agent 不得自行 `decide`。

## 每周复盘要回答的问题

1. 这周按规则做了几笔？有没有一次是"感觉"下的单？
2. 哪一笔最不该做？违反了哪条纪律？
3. 打法的滚动期望在上升还是下降？
4. 有没有新的观察值得写成假设卡？

## 知识从哪来

- 用户投喂（书、文章、复盘、盘感）→ `knowledge-intake`；
- 自己的亏损单（连续止损、卖太早/太晚）→ 提炼成检查清单；
- 回测里的反直觉发现（例如"消融显示某条规则没用"）→ 提案调整。

## 不做什么

- 不做参数网格搜索（过拟合工厂）；
- 不因为"最近赚钱了"就加大仓位（仓位由风险层决定）；
- 不频繁改打法：一次只动一个变量，改动要能追溯到一次回测。等纸面数据说话。
