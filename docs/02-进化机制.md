# 进化机制：怎么"越来越像一个好交易员"

## 核心原则

**不靠聊天积累，靠可证伪的闭环积累。** 每一条知识、每一次复盘，最终都要落成
一个可以被数据检验的假设；检验不过就淘汰，不心疼。

## 四步循环

```
知识/教训 ──→ 假设卡 ──→ 回测 ──→ 纸面跟踪 ──→ 晋级 or 淘汰
   │            │           │          │
   │            │           │          └─ 满 20 笔：期望>0 晋级；滚动 20 笔 <-1% 降级
   │            │           └─ 样本内外 + 随机基准 + 消融（strategy-lab 全自动）
   │            └─ 必须能写成条件树；写不出就不是可交易知识
   └─ 原文存 knowledge/，一字不改
```

## 三种状态

| 状态 | 含义 | 能否交易 |
|---|---|---|
| `candidate` | 有回测但没纸面数据 | **不能**，只观察 |
| `tracking` | 回测通过，纸面跟踪中 | **能**，但仓位减半 |
| `verified` | 纸面 ≥20 笔且期望 >0 | 能，按标准仓位 |
| `retired` | 衰减或证伪 | 不能，保留记录 |

## 三道闸（防止 Agent 把自己优化没了）

1. **风险层不可自改**：`risk.json` 的仓位、笔数、熔断阈值只有人类能改。
   Agent 只能改「选什么、什么时候买卖」。
2. **新规则先进候选**：任何新知识不得直接用于交易，必须先回测 + 纸面。
3. **晋级要批准**：Agent 出提案卡，人类回「批准」才写入 playbook 并 git 提交。

## 提案卡格式

```markdown
## 提案 PROP-YYYYMMDD-01
- 触发：PB-001 滚动 20 笔期望降到 +0.8%（阈值 +1.5%）
- 证据：runs/xxx（n=62，胜率 52%，盈亏比 1.7）
- 建议：把「箱体宽度 ≤18%」收紧到 ≤14%，或降级为 candidate
- 影响：预计信号减少 30%，期望回升到 +2.1%（回测）
- 需要你决定：A 采纳 / B 只降级 / C 不改，继续观察
```

## 每周复盘要回答的问题

1. 这周按规则做了几笔？有没有一次是"感觉"下的单？
2. 哪一笔最不该做？违反了哪条纪律？
3. 打法的滚动期望在上升还是下降？
4. 有没有新的观察值得写成假设卡？

## 知识从哪来

- 用户投喂（书、文章、复盘、盘感）→ `knowledge-intake`；
- 自己的亏损单（连续止损、卖太早/太晚）→ 提炼成检查清单；
- 回测里的反直觉发现（例如"消融显示某条规则没用"）→ 提案调整。

## 不做什么

- 不做参数网格搜索（过拟合工厂）；
- 不因为"最近赚钱了"就加大仓位（仓位由风险层决定）；
- 不频繁改打法：一次只动一个变量，改动要能追溯到一次回测。等纸面数据说话。
