# 盘中监控

`routines` 在 10:30 / 11:20 / 13:30 / 14:45 各检查一次；两次之间如果价格击穿止损，
最多会晚 40–80 分钟。`scripts/monitor.py` 补上这个空档。

## 两种跑法

**一次性**（推荐，交给 Windows 计划任务或 routines 之外的调度器）：

```powershell
python scripts\monitor.py --once
```

**常驻**（自己循环，默认每 180 秒）：

```powershell
python scripts\monitor.py --loop --interval 180
```

## 它做什么

1. 读 `trader/paper/account.json` 的持仓；
2. 用行情技能（`quote.cmd`，`--max-staleness 300`）取现价；
3. 判断：
   - 现价 ≤ 止损价 → `stop`
   - 现价 ≥ 止盈价 → `target`
   - 当日买入的票（T+1）不卖，只标注「明日处理」；
4. 触发时：
   - 追加到 `trader/paper/alerts.jsonl`（审计）；
   - 写一条事件到 `~/.dsh/feishu-im/inject.json`，交易台会话 2 秒内被唤醒，
     由 Agent 按 `a-share-trader` 规则卖出并写 journal。

## 常驻调度（已配置）

Windows 计划任务 `DSH-AShare-Monitor`：**周一至周五 09:25 起、每 5 分钟一次、持续 5 小时 40 分**
（约到 15:05），执行 `pythonw.exe scripts\monitor.py --once`（无窗口）。

```powershell
schtasks /Query /TN "DSH-AShare-Monitor" /FO LIST     # 状态与下次运行时间
schtasks /Run   /TN "DSH-AShare-Monitor"              # 立即跑一次
schtasks /Change /TN "DSH-AShare-Monitor" /DISABLE    # 停用
schtasks /Delete /TN "DSH-AShare-Monitor" /F          # 删除
```

注意：任务默认「仅登录时运行」。要开机即跑（不登录）需要改任务安全选项并保存凭据，
那属于系统级改动，暂不做——反正交易台会话本身也需要 Desktop 在跑。

## 参数

| 参数 | 说明 |
|---|---|
| `--once` / `--loop` | 跑一次 / 常驻 |
| `--interval 180` | 循环间隔（秒），最小 30 |
| `--prices file.json` | 用给定价格（测试用，格式 `{"sz.000788": 4.5}`） |
| `--account path` | 用别的账户文件（测试用） |
| `--dry-run` | 只打印，不写 alerts、不注入 |
| `--no-inject` | 只记账，不唤醒 Agent |

## 已验证

- 空仓：`09:02:38 空仓，无需监控`
- 测试账户（sz.000788 成本 5.00、止损 4.60）+ 价格 4.50：
  `触发 stop: sz.000788 @ 4.50`

## 为什么不用飞书里的定时消息做这件事

定时消息的最小粒度是「一分钟一次、到点触发」，而价格可能在任何一分钟击穿；
真正需要的是「价格事件驱动」。监控脚本负责发现，inject 通道负责唤醒，
Agent 负责决策——三段解耦，任何一段坏了都能单独排查。

## 注意

- 免费行情有延迟（约 3 秒一笔，可能 stale），触发价和真实成交会有差异；
  模拟盘按「快照价 × (1−滑点)」记账，比理想价保守。
- 只监控**已持仓**的止损止盈；建仓信号仍由盘前/收盘例程处理。
- alerts.jsonl 只追加不修改，复盘时可以回放「当时是什么价格触发的」。
